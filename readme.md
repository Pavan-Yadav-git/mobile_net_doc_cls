##  Document Classification using MobileNetV3-Small

This project implements a deep learning model for **document image classification** using **MobileNetV3-Small (100 width multiplier)**.
## https://docs.pytorch.org/vision/stable/models.html

## https://arxiv.org/abs/1905.02244 
###  Overview
The model is designed to classify document images into predefined categories with a focus on **efficiency, speed, and deployment readiness**. It leverages the lightweight architecture of MobileNetV3, making it suitable for mobile and edge devices.

###  Model Architecture
- Base Model: MobileNetV3-Small (100)
- Type: Convolutional Neural Network (CNN)
- Optimized for: Low latency and resource-constrained environments
- Key Features:
  - Depthwise separable convolutions
  - Lightweight architecture
  - High efficiency with competitive accuracy

###  Use Case
- Automatic document sorting and classification
- Intelligent document management systems
- Mobile/edge AI applications

###  Key Benefits
- Fast inference time
- Small model size
- Suitable for real-time applications
- Easy deployment on lightweight devices

###  Summary
A compact yet effective document classification model built using MobileNetV3-Small, optimized for real-world deployment scenarios where speed and efficiency matter.
